# Instructions pour capturer l'image hero de MailZen

## Option 1: Capture manuelle
1. Ouvrez https://mailzen.netlify.app/ dans votre navigateur
2. Prenez une capture d'écran de la section hero (partie supérieure avec le titre principal)
3. Redimensionnez l'image à 640x360px pour les cartes de projet
4. Sauvegardez l'image comme `/Users/admin/Desktop/windsurf/virtuos/template/mailzen/mailzen-hero.png`

## Option 2: Utilisation d'un outil de capture
```bash
# Avec screencapture (macOS)
screencapture -i /Users/admin/Desktop/windsurf/virtuos/template/mailzen/mailzen-hero.png

# Ou utilisez Cmd+Shift+4 pour capturer une zone spécifique
```

## Option 3: Téléchargement direct
Si MailZen a des images statiques, vous pouvez les télécharger directement depuis leur site.

Une fois l'image capturée, elle sera automatiquement utilisée dans:
- La section "Projets en vedette" sur la page d'accueil
- La page "Projets récents" 
- La page de détails du projet MailZen
